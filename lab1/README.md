## Цель работы

Разработать MVP Telegram-бота для автоматизации взаимодействия покупателей с небольшим розничным магазином.

## Реализованные функции

- Главное меню и справка.
- Каталог из шести демонстрационных товаров.
- Фильтрация товаров по категориям.
- Поиск по названию и описанию.
- Добавление и удаление товаров из избранного.
- Корзина с расчётом общей стоимости.
- Проверка доступного количества товаров.

## Технологии

Python 3.14, python-telegram-bot 22.8, python-dotenv, Telegram Bot API, Git и GitHub.

## Запуск проекта

1. Установить Python и создать виртуальное окружение.
2. Установить зависимости из `requirements.txt`.
3. Создать `.env` на основе `.env.example` и указать `BOT_TOKEN`.
4. Запустить `python lab1/bot.py` из корня репозитория.

## Ограничения MVP

Каталог демонстрационный. Корзина и избранное сохраняются только в памяти работающего приложения. После перезапуска данные теряются. Оплата не предусмотрена.
