## Используемый ИИ-инструмент

ChatGPT — помощь в проектировании, генерации кода,
диагностике ошибок и подготовке тестирования.

Cursor — среда разработки и редактирования кода.

## Итерация 1. Проектирование MVP

**Задача:** разработать Telegram-бота для небольшого
розничного магазина.

**Требования:**
- Python и Telegram Bot API;
- команды /start, /help, /catalog, /about;
- меню с кнопками;
- демонстрационный каталог товаров;
- безопасное хранение токена в .env.

**Результат:** создана первая работающая версия bot.py.

## Итерация 2. Диагностика подключения

**Проблема:** при запуске появилась ошибка
telegram.error.TimedOut.

**Действия:**
- проверка TCP-соединения;
- проверка HTTPS через curl;
- проверка HTTPS через Python httpx;
- проверка Telegram Bot API методом getMe.

**Результат:** подтверждена доступность API.
При повторном запуске бот начал отвечать.

## Итерация 3. Расширение функциональности

**Задача:** улучшить MVP Telegram-бота.

**Требования:**
- каталог из шести товаров;
- фильтрация по категориям;
- поиск по названию и описанию;
- избранное;
- корзина;
- подсчёт стоимости;
- проверка доступного количества товара.

**Результат:** реализована версия
SmartShop Assistant 2.0.

## Итерация 4. Функциональное тестирование

Проверены следующие сценарии:
- запуск бота;
- просмотр каталога;
- выбор категории;
- поиск товара;
- добавление в избранное;
- добавление товара в корзину;
- расчёт стоимости;
- очистка корзины.

**Результат:** основные сценарии выполнены успешно.

## Приложение А. Примеры запросов к ИИ

Ниже представлены реконструированные формулировки
технических задач, поставленных ChatGPT в процессе
разработки. Они отражают фактические этапы проекта,
но не являются дословными цитатами из переписки.

### Промпт 1. Создание MVP

Разработай Telegram-бота на Python для небольшого
розничного магазина SmartShop Assistant.

Реализуй команды /start, /help, /catalog, /about,
кнопочное меню и демонстрационный каталог товаров.

Используй python-telegram-bot и python-dotenv.
Токен должен храниться в файле .env, который
не отправляется в GitHub.

### Промпт 2. Диагностика ошибки

При запуске Telegram-бота возникает ошибка
telegram.error.TimedOut.

Предложи последовательную диагностику сетевого
соединения, доступности Telegram Bot API и
правильности конфигурации приложения.

Не выводи API-токен в консоль и не предлагай
публиковать его в открытых источниках.

### Промпт 3. Расширение функциональности

Расширь Telegram-бота SmartShop Assistant.

Добавь каталог из шести товаров, категории,
поиск по названию и описанию, избранное,
корзину и автоматический расчёт стоимости.

Используй асинхронные обработчики сообщений
библиотеки python-telegram-bot.

Для MVP храни пользовательские данные
в оперативной памяти.

### Промпт 4. Подготовка тестирования

Подготовь сценарии функционального тестирования
Telegram-бота SmartShop Assistant.

Необходимо проверить запуск приложения,
отображение каталога, фильтрацию товаров,
поиск, работу избранного, добавление товаров
в корзину, расчёт суммы и очистку корзины.

Представь результаты в виде таблицы,
пригодной для включения в Markdown-отчёт.
