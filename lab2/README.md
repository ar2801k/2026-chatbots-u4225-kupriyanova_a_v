## Задача

Подключить постоянный источник данных к Telegram-боту из лабораторной №1. В версии 3.0 используется локальная реляционная база SQLite.

## Функции

- Каталог товаров и поиск по названию/описанию из SQLite.
- Категории товаров.
- Избранное и корзина, сохраняющиеся после перезапуска.
- Учебные заявки без оплаты; состав заказа и сумма фиксируются в базе.
- Учёт остатков товаров при оформлении заявки.
- Просмотр десяти последних заявок пользователя.

## Структура

- `bot.py` — обработчики Telegram-команд и сообщений.
- `database.py` — схема SQLite и операции с данными.
- `check_db.py` — диагностический скрипт просмотра списка таблиц и числа записей.
- `requirements.txt` — зависимости.
- `REPORT.md` — отчёт с результатами тестов.
- `PROMPTS.md` — журнал использования ИИ.
- `screenshots/` — иллюстрации тестирования.

## Запуск из корня репозитория

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r lab2/requirements.txt
```

Создайте `lab2/.env` с переменной `BOT_TOKEN=...` (или используйте локальный `lab1/.env` на учебном компьютере). **Никогда не коммитьте `.env` и токены.**

```powershell
python lab2/bot.py
```

При первом запуске `database.py` создаёт `smartshop.db` и заполняет каталог шестью демонстрационными товарами. SQLite-файл исключён из Git через `.gitignore`. При повторном запуске записи не удаляются. Запускайте только **одну** версию бота с данным токеном одновременно.

## Проверка базы

Остановите бота перед диагностикой и выполните:

```powershell
python lab2/check_db.py
```

## Ограничения

Локальная SQLite-база предназначена для учебной демонстрации. При переносе проекта на другой компьютер база будет создаваться заново; существующие пользовательские данные автоматически не переносятся. Для будущего облачного развёртывания необходимо отдельно предусмотреть постоянный диск либо внешнее хранилище. Реальная оплата отсутствует.
