## Развёртывание

- Платформа: Railway, среда `production`.
- Корневая папка сервиса: `/lab3`.
- Команда запуска: `python bot.py`.
- Переменная окружения `BOT_TOKEN` задаётся только в Railway.
- База SQLite должна находиться по пути из `DATABASE_PATH=/data/smartshop.db` на подключённом постоянном томе `/data`.
- Не запускайте локальный и облачный экземпляры бота одновременно (Telegram polling).

## Запуск локально

1. Создать виртуальное окружение и установить `lab3/requirements.txt`.
2. Локально задать `BOT_TOKEN` (секрет не коммитить) и при необходимости `DATABASE_PATH`.
3. Выполнить `python lab3/bot.py` из корня репозитория.
